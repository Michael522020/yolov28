# YOLOv28

الدليل نفسه متوفر بسبع لغات. روابط التبديل في أعلى الصفحة.

هذا المستودع كاشف أجسام مستقل بلا مربعات إرساء (anchor-free): الشبكة، ودالة الخسارة، والتدريب، والتنبؤ، وتصدير ONNX. تبدأ الأوزان من تهيئة عشوائية. رُوجعت الوثائق في أكتوبر 2026. كانت أحدث عائلة منشورة آنذاك لدى Ultralytics هي [YOLO26](https://docs.ultralytics.com/models/yolo26) (يناير 2026). أما [YOLO27](https://docs.ultralytics.com/models/yolo27) فكانت ما تزال معاينة، من غير أوزان أو تنفيذ علنيين. إذا صدرت لاحقًا نسخة رسمية أحدث، فالمرجع هو وثائق Ultralytics.

كود هذا المستودع برخصة MIT. كود Ultralytics غير مضمّن هنا. يُشار إلى هذا المشروع بوصفه تنفيذًا مستقلًا.

إصدار الكود الحالي هو 0.2.0. هذا الإصدار يغيّر الشبكة، فنقطة الحفظ من 0.1.0 لا تُحمَّل ويجب إعادة التدريب.

| YOLOv6 | منشور | عمود فقري معاد ضبط معاملاته، ورأس منفصل |
| YOLOv7 | منشور | E-ELAN |
| YOLOv8 | منشور | تنبؤ بلا إرساء، وتعيين محاذٍ للمهمة، وDFL |
| YOLOv9 | منشور | GELAN ومعلومات تدرج قابلة للبرمجة |
| YOLOv10 | منشور | فرع واحد-إلى-كثير وفرع واحد-إلى-واحد |

وثائق Ultralytics تصف YOLO12 بأنه نموذج مجتمعي، وتعرض YOLO26 بوصفه العائلة الحالية للعمل الجديد.

## الشبكة

يجب أن يكون ارتفاع الدخل وعرضه من مضاعفات 32. خطوات الكشف الثلاث هي 8 و16 و32.

- الساق لفّتان بخطوة 2، ثم GateCSP.
- MixUnit يمزج بسوفتماكس، وعلى مستوى كل قناة، لفّ عمق 3×3 ولفّ عمق 5×5، ثم يطرح سياق تجميع متوسط 3×3. انحياز بوابة المتبقي يبدأ عند -4، فيبدأ البلوك قريبًا من تحويل المطابقة.
- كل مقياس من مقاييس الكشف الثلاثة يمر عبر StripGate قبل الرأس. تُبنى البوابة من متوسط أفقي ومتوسط رأسي. انحيازها يبدأ عند 4، فتكون في البداية شبه مفتوحة.
- GateCSP يقسم القنوات: فرع يكدّس وحدات MixUnit، وفرع يمر كما هو، ثم يُدمجان.
- خريطة أدنى دقة تمر عبر PyramidPool: ثلاث عمليات تجميع أعظمي 5×5 متتالية، تُضم إلى الميزات قبل التجميع.
- العنق PAN على P3 وP4 وP5.
- الرأس يفصل التصنيف عن الصناديق. الصندوق مسافة يسار/أعلى/يمين/أسفل بعد softplus، بوحدة الخلية، تُضرب في الخطوة لتصير بكسلات على دخل الشبكة. مخرجات الفئات لوجتات. هذا الرأس لا يستخدم سلال DFL.
- رأس واحد-إلى-كثير يُبقي حتى 13 عينة موجبة لكل صندوق حقيقي، مرتبة حسب درجة الفئة مضروبة في IoU. التنبؤ يطبّق NMS حسب الفئة.
- رأس واحد-إلى-واحد يُبقي عينة موجبة واحدة لكل صندوق حقيقي. `--end2end` يُبقي أعلى الصناديق حسب الدرجة ويتجاوز NMS.
- إذا لم يحتوِ صندوق حقيقي على مركز خلية، تُستخدم أقرب نقطة شبكة عينةً موجبة.

خسارة التدريب هي CIoU على العينات الموجبة مع BCE-with-logits في كل المواضع. المحسّن AdamW. وصفة التدريب المذكورة في وثائق YOLO26 هي MuSGD وSTAL وProgressive Loss. هذا المستودع يستخدم القيم الافتراضية الخاصة به أدناه.

## التثبيت

```bash
pip install -r requirements.txt
```

يستخدم التدريب والتنبؤ وحدة الرسوم عند توفر CUDA. `--device cpu` أو `--device cuda` يحدد الجهاز. على Windows القيمة الافتراضية لـ `--workers` في DataLoader هي 0.

تصدير ONNX يحتاج حزمة إضافية:

```bash
pip install onnx
```

## تجربة على بيانات اصطناعية

المجموعة الاصطناعية ضوضاء عليها مستطيلات ملونة، وثماني صور تدريب. الأمر يتحقق فقط من أن التدريب والتحقق وكتابة نقطة الحفظ تكتمل. بعد حقبة واحدة يمكن أن تكون mAP50 للتحقق مساوية 0.

```bash
python -m yolov28.train --demo --epochs 1 --batch 4 --imgsz 320
```

تُكتب الأوزان في `runs/train/exp/weights/last.pt` و`best.pt`. إذا كان المجلد موجودًا، فالتشغيل التالي يستخدم `exp2` ثم `exp3`.

## تدريب بياناتك

المجلدات تتبع تنسيق نص YOLO الشائع:

```text
datasets/custom/
  images/train/a.jpg
  labels/train/a.txt
  images/val/b.jpg
  labels/val/b.txt
```

كل سطر تسمية هو `الفئة xc yc w h`. قيم الصندوق الأربع منسوبة إلى عرض الصورة الأصلية وارتفاعها. انظر `configs/dataset.example.yaml`.

```bash
python -m yolov28.train --data configs/dataset.example.yaml --scale n --epochs 100 --batch 8 --imgsz 640
```

يشمل التعزيز Mosaic لنحو 75% من العينات، وقلبًا أفقيًا عشوائيًا، وHSV، وletterbox. إذا استمر التدريب عشر حقب على الأقل، يُوقف Mosaic في آخر 10% من الحقب. `--demo` لا يستخدم Mosaic، و`--no-mosaic` يوقفه على بيانات حقيقية. التحقق وملفا `last.pt` و`best.pt` يستخدمان متوسطًا متحركًا أسيًا للأوزان بمعامل تلاشي 0.999. معدل التعلم `0.001`، وتضاؤل الأوزان `0.0005`، وتُقص التدرجات عند 10. إذا زاد عدد الحقب على واحدة، فالحقب الثلاث الأولى تسخين خطي ثم هبوط جيب التمام. تشغيل حقبة واحدة يستخدم معدل الأساس مباشرة. معامل خسارة الصندوق 2.0، ومعامل التصنيف 0.5، وفرع واحد-إلى-واحد يُضرب في 1.0. عند وجود مجموعة تحقق، يُختار `best.pt` حسب mAP50-95 للتحقق.

`--scale` يقبل `n` أو `s` أو `m` أو `l` أو `x`.

## التنبؤ

```bash
python -m yolov28.predict --weights runs/train/exp/weights/last.pt --source image.jpg --conf 0.25
```

`--source` قد يكون صورة واحدة أو مجلدًا. تُحفظ الرسوم تحت `runs/predict/exp/` على الصورة الأصلية. الصناديق المُعادة ببكسلات تلك الصورة.

رأس واحد-إلى-واحد:

```bash
python -m yolov28.predict --weights runs/train/exp/weights/last.pt --source image.jpg --end2end
```

نقطة حفظ مهيأة عشوائيًا، أو مدرَّبة لبضع خطوات فقط، ما تزال تُخرج صناديق كثيرة منخفضة الجودة. ارفع `--conf` لإخفاء المزيد منها.

## تصدير ONNX

```bash
python -m yolov28.export --weights runs/train/exp/weights/last.pt --imgsz 640 --output yolov28n.onnx
```

دخل التصدير هو `1×3×imgsz×imgsz`. الخرج `(1, anchors, 4+عدد الفئات)`: الأرقام الأربعة الأولى xyxy على لوحة دخل الشبكة، تليها درجات الفئات بعد السيغمويد. يبقى NMS خارج المخطط. حجم الدفعة ثابت عند 1. `--end2end` يختار رأس واحد-إلى-واحد، والمخطط يظل من غير NMS.

## واجهة بايثون

```python
from yolov28 import YOLO

model = YOLO("n", nc=4)
model.train(demo=True, epochs=1, batch=4, imgsz=320, name="demo")
model.predict("image.jpg", imgsz=320, conf=0.25)
```

`YOLO("runs/train/demo/weights/last.pt")` يحمّل نقطة حفظ كتبها هذا المستودع.

## مقياس التحقق

mAP50 في السجل هي متوسط الدقة عند IoU يساوي 0.5. أما mAP50-95 فتأخذ متوسط عشر عتبات من 0.50 إلى 0.95 بخطوة 0.05. الفئات التي ليس لها حقيقة مرجعية في التحقق تُستبعد من المتوسط. يُختار `best.pt` حسب mAP50-95.
